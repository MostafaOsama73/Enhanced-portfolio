# Mostafa's Portfolio

A modern, responsive portfolio website template.

## Getting Started

1.  **Open `index.html`** in your web browser to view the site.
2.  **Edit `index.html`** in a text editor (like VS Code) to add your real information.

## Customization

### Content
Search for the following placeholders in `index.html` and replace them with your details:
- `[Professional Summary Placeholder]`
- `[Job Title]`, `[Company Name]`
- `[Project Name]`
- `email@example.com`

### Images
Replace the placeholder icons/divs with actual `<img>` tags pointing to your photos.

### Colors
You can change the color scheme by extracting the `style.css` file and modifying the `:root` variables:
```css
:root {
    --primary-color: #64ffda; /* Change this */
    --bg-color: #0a192f;      /* Change this */
}
```
